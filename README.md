# Morris Chuang Portfolio — production package

Static portfolio package prepared for `morrischuang.site`.

## Structure

- `index.html` — personal landing page with the three Selected Work cards.
- `work/index.html` — overview of ULTRA SCAN 03, MANTA 01 and FLEX 03.
- `work/ultra-scan/` — ULTRA SCAN 03 case study.
- `work/manta/` — MANTA 01 case study.
- `work/flex-03/` — FLEX 03 case study.
- `work/shared/` — shared styles and interaction code used by case-study pages.

No build step is required. Deploy the repository root as a static site / Worker static assets source.
