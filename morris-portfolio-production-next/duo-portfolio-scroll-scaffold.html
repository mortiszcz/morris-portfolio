01 / TA RESEARCH

PROJECT BACKGROUND.

從目標使用者研究出發，讓雙螢幕的性能、比例與工作流成為 Zephyrus Duo 的核心架構。

02 / PROJECT OBJECTIVES

THE NEXT ZEPHYRUS.

延續 Zephyrus 的高性能精神，將產品推向更具互動感的未來樣貌；靈感取自高性能車款的精準比例與機械張力。

03 / CONCEPT DEVELOPMENT

ARCHETYPE DEFINITION.

把娛樂與互動單元置入性能產品的架構，將雙螢幕從附加功能轉化為產品的核心識別。

04 / CONCEPT DEVELOPMENT

IDEATION.

從 Zephyrus 的既有設計語言出發，探索能抬升第二螢幕，同時保持穩定與完整視覺節奏的方案。

05 / REFINEMENT

FINAL DESIGN.

透過側邊倒角、輪廓與細部打磨，讓高性能結構與視覺張力收斂成可落地的產品語言。

06 / 2ND PANEL

DUO STEALTH HINGE.

第二螢幕成為隨時可喚起的協作與多工介面；Stealth Hinge 將支撐、轉動與視覺完整性整合在同一個機構裡。

08 / PROTOTYPING

TEST IT IN FULL SCALE.

以實體模型驗證比例、螢幕關係與轉軸運作，讓畫面上的選擇回到手感、重量與實際使用情境接受檢驗。

09 / DESIGN FEATURES

RGB / 65% KB + TP.

RGB keyboard、側邊散熱結構與 65% keyboard + touchpad 配置，讓性能需求、操作速度與視覺識別共同成立。

10 / FINAL DESIGN
